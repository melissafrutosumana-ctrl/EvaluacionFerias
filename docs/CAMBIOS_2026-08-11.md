# Resumen de cambios — EvaluacionFerias (11 agosto 2026)

## 1. Resultados divididos por categoría — Feria Expotecnica

Los resultados de la tabla de Puntajes ahora se agrupan por **categoría** cuando se filtra por Feria Expotecnica (DESAFIO STEAM / EMPRENDIMIENTO E INNOVACION).

## 2. Resultados divididos por categoría — Festival Estudiantil de las Artes

Los resultados también se agrupan por `categoria_festival` (Artes Visuales, Musicales, etc.) cuando se filtra por Festival de las Artes.

## 3. Puntaje escrito manual

Se agregó la posibilidad de que el administrador ingrese un **puntaje escrito manualmente** para proyectos evaluados de forma física (en papel), sin depender de que el juez lo ingrese digitalmente.

### Cómo funciona
- En la tabla de Puntajes (resultados_admin.html), cada proyecto muestra un botón **"✎ Ingresar manual"** en la columna Escrito.
- Al hacer clic aparece un campo inline (0–100) con botones Guardar / Cancelar.
- El puntaje manual **reemplaza** el promedio digital del escrito en el cálculo final.
- Si se borra el manual (campo vacío + Guardar), el sistema vuelve a usar los puntajes digitales de los jueces asignados como "Escrito".
- Si no hay manual ni jueces digitales, el puntaje final usa solo la Exposición.

### SQL requerido en Supabase
```sql
ALTER TABLE proyectos_ferias ADD COLUMN IF NOT EXISTS puntaje_escrito_manual NUMERIC;
```

### Todos los proyectos visibles
La tabla de Puntajes ahora muestra **todos los proyectos de la feria**, incluso sin jueces asignados, para permitir ingresar el puntaje manual desde el principio.

## 4. Feria Científica dividida por nivel educativo

Al registrar un proyecto de **Feria Científica y Tecnológica** ahora se selecciona primero el nivel, y los formularios PRONAFECYT se filtran automáticamente:

| Nivel | Formularios disponibles (Jueces) |
|---|---|
| Primaria (I y II Ciclos) | F11B - Quehacer Científico y Tecnológico |
| Secundaria - III Ciclo | F8B - Demostraciones / F9B - Investigación / F10B - Investigación y Desarrollo Tecnológico |
| Secundaria - Ed. Diversificada | F9B - Investigación / F10B - Investigación y Desarrollo Tecnológico |
| Educación Especial | F12B - Sumando Experiencias / F13B - Mi Experiencia Científica |

### Formularios C automáticos
Cada formulario B tiene su par C para la evaluación escrita:
- El juez asignado como **"Exposición"** usa el formulario **B**
- El juez asignado como **"Escrito"** usa automáticamente el formulario **C** correspondiente

Esto aplica a todos los pares: F8B↔F8C, F9B↔F9C, F10B↔F10C, F11B↔F11C, F12B↔F12C.

### F14 — Formulario de interacción
El F14 es para que los **estudiantes** evalúen su interacción con el juez, no al revés. Por esto no se incluyó en los rubrics de evaluación.

### Los resultados se agrupan por nivel
En resultados_admin.html, al filtrar por Feria Científica, los proyectos aparecen agrupados por nivel (Primaria / Secundaria - III Ciclo / Secundaria - Ed. Diversificada / Educación Especial).

## 5. Corrección de operadores rotos por el formateador

El formateador automático de VS Code separó los operadores `?.` y `??` con espacios (`? .` y `? ?`), causando el error `"Unexpected token '?'"` que impedía iniciar sesión. Se corrigieron mediante script Python para garantizar que no queden instancias rotas.

## Notas técnicas

- **Base de datos**: Supabase (proyectos_ferias, evaluaciones_proyectos, asignaciones_jueces, usuarios)
- **Campo nuevo**: `puntaje_escrito_manual NUMERIC` en tabla `proyectos_ferias`
- **Sin columna nueva para nivel**: El nivel educativo se deriva del código del formulario (`categoria_pronatecyt`) — no requiere migración adicional
- **Repositorio**: https://github.com/melissafrutosumana-ctrl/EvaluacionFerias
