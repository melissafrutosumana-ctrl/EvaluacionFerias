# EvaluacionesCTPM

Aplicación para organizar y dar seguimiento a las evaluaciones de las ferias estudiantiles del Colegio Técnico Profesional de Matapalo.

Permite administrar ferias y proyectos, gestionar usuarios, asignar proyectos a los jueces, registrar calificaciones y observaciones, y consultar resultados y reportes.

Cuenta con espacios de trabajo para el personal administrador y los jueces, con acceso a las funciones que cada rol necesita.
